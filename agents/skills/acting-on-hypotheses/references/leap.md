# Leap — COMMIT & REALIZE: stake a kept output, then make the hypothesis true

> Scope: the ONLY phase that **stakes a kept output** and produces the outcome itself (仮説を正解にする).
> Leap changes confidence only via reality (post-commit), never via a cheap discard-intent test (that is
> Loop). Leap is not "be bold theater" — its boldness is gated by three written artifacts below.

| comes from | this file produces | goes to |
|---|---|---|
| `loop.md` once fatal risk on the load-bearing node is retired (decision-sufficient, NOT 100%) | a committed decision with a written WIN/KILL/LOSS triple + a door-type classification | execution; reality-divergence routes back to `map.md` (demote to more Loop) or honors the kill condition |

## §1 — The action cut that keeps Leap distinct from Loop: INTENT-AT-DESIGN

A **Leap action** is one you pre-commit to **KEEP and BUILD ON** (scope sized to the OUTCOME). A **Loop
action** is one you pre-commit to **THROW AWAY** (scope sized to the SIGNAL). The cut is categorical by
**intent-at-design**, not a reversibility gradient. A staged/reversible Leap is **STILL Leap** — you keep
and depend on stage 1.

There is no keep-possible exception. A deterministic, bounded, reversible try whose result has no
expensive/irreversible downstream exposure is routed by STEP 0 to the domain/plain executor and returns
to `directing-research-sections` under the current mandate and charter; calling it a Leap would be
ceremony. If expensive/irreversible work does ride on
the result, Loop may use a cheap **discard-intent** probe to protect the later decision, and only the
subsequent kept commitment is Leap.

## §2 — EVALUATE → DECIDE → REALIZE

- **EVALUATE** on **確信度(now earned) × 影響度**. Do **not** default to the safe small bet — the book's
  「君の仮説は小さくまとまっているね」 anti-pattern (small-bet disease, `anti-patterns.md`). Weight 影響度:
  確信度は後で上げられるが影響度は上げづらい. Resisting the small bet is the EVALUATE step's job.
- **DECIDE** — state the chosen approach and WHY in one line; commit. Indecision past decision-sufficiency
  is itself a failure (it is Loop's over-learning wearing a Leap costume — force the decision).
- **REALIZE** — 仮説を正解にする: when reality diverges, **adjust execution / pivot toward the goal before
  declaring the hypothesis dead** (you can make a hypothesis true by execution — environment and premises
  are partly yours to move). BUT the kill condition (§3) overrides sunk cost — REALIZE is not "push
  forever".

## §3 — The WIN / KILL / LOSS triple (the load-bearing Leap artifact — fill it in BEFORE committing)

This is the artifact that turns 大胆 from slogan into discipline. **Write all three BEFORE acting** — set
before, so sunk cost cannot later rewrite them. (Mirrors loop.md's pre-committed threshold.)

```
WIN  CONDITION  — observable outcome that means the bet paid off:  ____________________
                  (a number / event you will SEE, not a feeling)
KILL CONDITION  — observable outcome at which you WITHDRAW, on a deadline:  ____________
                  (the line that overrides sunk cost; set the trigger AND the date)
LOSS CAP        — the survivable maximum you can lose and continue:  _________________
                  (許容可能な損失 — money / time / reputation you pre-authorize to spend)
```

If you cannot fill the KILL line, you are not committing — you are drifting; do not Leap yet. If the LOSS
CAP is not survivable, this is not a Leap to make at this 確信度 → go to §4.

## §4 — Reversibility sizing (door-type checklist) — provenance: EXTERNAL Amazon lore, NOT 仮説行動

> **Provenance tag.** "One-way vs two-way doors" / reversible-bet sizing is **Amazon / Bezos lore**
> (imported lineage), **not** from 馬田『仮説行動』. The only Bezos content actually in the decks is the
> 70% sufficiency rule. This section is a deliberate external addition, tagged like `boundaries.md` tags
> lean/OODA/effectuation — use it, but do not read it as a deck claim. The deck's native Leap content is
> §2 (evaluate/decide/realize) + 「大きく考え、小さく踏み出せ」.

| door type | reversibility | sizing rule |
|---|---|---|
| **Two-way door** | reversible / bounded loss | Leap **boldly even at mid 確信度** — asymmetric upside, you can walk back through. Do not demand more Loop here; over-testing a reversible bet is waste. |
| **One-way door** | irreversible / unbounded loss | **Demand more Loop** (retire more risk first) OR **restructure into staged/reversible commits** (turn the one-way door into a sequence of two-way doors). Do not Leap a one-way door at mid 確信度. |

**大きく考え、小さく踏み出せ** — think big (high-影響度 target), step small (size the irreversible
exposure down via staging). The boldness lives in the 影響度 of the target, not in the size of the
irreversible loss.

## §5 — Confidence also moves in Leap — but as a byproduct, not the goal

Confidence moves during Leap too (REALIZE confirms or diverges), but that is a **byproduct of staking**;
only Loop *designs a cheap discard-intent test* to move it. So do not relabel a Leap as "more learning" to
dodge the decision (`loop.md` §6 STOP), and do not claim Loop monopolizes all confidence movement.

## Leap anti-patterns (run this on your own output)

| tell | what's wrong | recovery |
|---|---|---|
| Committed with no written KILL line | not a commitment, a drift | fill the WIN/KILL/LOSS triple before acting (§3) |
| Pushed past the kill condition "because we've invested so much" | sunk-cost override | the kill line wins; withdraw or restructure (§2 REALIZE / §3) |
| Picked the safe small bet by default | small-bet disease (君の仮説は…) | re-evaluate weighting 影響度; resist the default (§2 EVALUATE) |
| Leapt a one-way door at mid 確信度 | reckless irreversible Leap | demand more Loop or stage it into two-way doors (§4) |
| Over-tested a reversible bet | treated a two-way door as one-way | bounded loss + asymmetric upside = GO; stop looping (§4) |
| Called a cheap reversible executor trial a Leap solely because you might keep it | gate bypass / commitment ceremony | route it out under STEP 0 and return the raw result + provenance to directing-research-sections (§1) |
