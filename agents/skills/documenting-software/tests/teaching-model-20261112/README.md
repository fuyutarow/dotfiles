## Failure and intervention

Root stated before editing: the reviewer treated existing information's arrangement and consistency
as sufficient, without taking responsibility for a model the reader can explain and use in a new
case. Existing guidance already required reader decisions and operation traces. This is therefore
both an application failure and a candidate communication/attention problem, not proof of an
intrinsically defective principle or a model/harness as sole cause.

The revised opening owns reader understanding: familiar problem, worked input, mechanism,
result/refusal and a changed condition. Page questions and responsibilities precede directories.
Different backgrounds need different entry paths; exact API lookup need not teach the whole system.
Examples and recommendations must not strengthen a source contract. Responsibility classification,
binding rule preservation and evidence-scoped review remain in the body. Historical corpus detail
is condensed to its existing evidence home; its limits and label meanings remain in the entrypoint.
The final entrypoint is roughly the same length as the baseline; no new skill or runtime gate is added.

This is a local response to observed failures, not a new empirical theory of teaching. The previously
cited source classification/audit does not establish reader effects. Newly requested upstream source
surveys for consumer documentation are separate work, not evidence of this revision's effectiveness.
