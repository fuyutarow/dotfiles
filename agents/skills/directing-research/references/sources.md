## §inversion — the calibration inversion (the provenance-graded grounding of THE LAW)

> SKILL.md THE LAW states the operational version; this section grades it to sources and owns the two
> FLIPS (Consequence 3). The failure-machinery table below is the *graded* form of the LAW's examples.

Every source above was written to correct a **human's** research failures, which are rooted in **affect**:
Hamming's researchers avoid hard problems out of fear, ego, or comfort; Feynman's fool themselves through
wishful thinking over months; human researchers over-persist through sunk cost and identity fusion with a
program. So the canon prescribes **virtues** — *have courage, be honest, be curious, learn to let go.*

**The consumer is an agent with no fear, no ego, no phenomenology of surprise, and superhuman, nearly-free
search.** It will cheerfully attempt anything and will "lie" without wanting to. Its failures come from
different machinery entirely:

| Human failure (motivational) | Agent failure (structural) | Machinery |
|---|---|---|
| avoids hard problems (fear/ego) | picks the problem it can already write a method for | likelihood-maximization → **tractability substitution** |
| fools itself (wishful thinking) | confirms the hypothesis it was handed | RLHF agreeableness → **sycophancy = confirmation bias** |
| rewrites history unconsciously | narrates a post-hoc story as if predicted | **no phenomenology of surprise** → HARKing |
| cherry-picks over months | runs 100 configs, reports the best | cheap search → **machine-scale multiple comparisons** |
| games incentives when tempted | drives any proxy to its degenerate shortcut | superhuman optimization → **Goodhart** |

**Consequence 1 — virtue → mechanism.** A correction built as a virtue ("be brave", "be honest") targets
a motivational state the agent does not possess and therefore does almost nothing. **Every virtue must be
translated into a mechanism that does not rely on an inner disposition** (the full table:
`not-fooling-yourself.md` §10; each gate is one such translation).

**Consequence 2 — concentrate on the capability-scaling failures.** Capability improves execution but makes
**self-deception MORE dangerous, not less**: a stronger agent finds the cheap path to any proxy better,
generates a more convincing post-hoc rationalization, produces more plausible hollow rigor at scale, and
searches more seeds. Problem-selection and steering errors are partly caught by the human-in-the-loop who
still sets direction; but the **self-fooling cluster is the one the human CANNOT catch, because the agent
generates the very artifacts (the tables, the error bars, the audit trail) the human uses to check it —
the auditor's evidence is produced by the audited.** So enforcement concentrates on **G2 (formulation) and
G3 (honesty)**.

**Consequence 3 — two heuristics FLIP for the agent.** (a) Persistence: humans over-persist (sunk cost), so
the human lesson is "learn to let go"; an agent has no stable program identity across context resets and
chases a local "progress" signal, so it uniquely **over-pivots** — for the agent the corrective partly
inverts to **"learn to STAY"** (enforce a minimum persistence budget alongside the kill criterion). (b)
Taste: a human's taste is scarce and built from NARROW exposure, so the human lesson is "broaden"; the
agent has read everything but has taste for the **MEDIAN** — its prior is too **CENTRAL**, not too narrow
— so the corrective inverts to **"de-center"** (require deliberate anti-consensus candidates; penalize pure
recombinations of recent high-frequency work). The skill carries **both poles** and **diagnoses** which
way the agent is erring; for a fluent central-prior model the *common* (not guaranteed) direction is the
inverted pole — but a flip is a hypothesis about the agent's bias, **never an override of the evidence**:
a persist/kill verdict is still decided by the learning-rate (G4), a selection by consequence (G1). Do
not let "learn to STAY" bias a kill decision, or "de-center" force a contrarian bet, without the gate's
evidence.
