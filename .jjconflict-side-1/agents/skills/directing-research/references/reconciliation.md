# Scoped tensions in creative research

Research advice often conflicts because it omits the deciding condition. Keep the poles; name the
moderator for this case.

| Tension | Runtime moderator | Result |
|---|---|---|
| expose premises vs invent alternatives | Is the current bottleneck an implicit premise in one received frame, or the absence of candidate frames/theses? | `surfacing-blind-spots` first for excavation; then construct here or generate in `forging-novel-theses` |
| breadth vs depth | Has one typed sweep exposed distinct assumption classes, and which 1–3 assumptions can still change the decision? | sweep once, then drill the load-bearing thread; do not substitute an endless checklist or a single tunnel |
| important vs attackable | Is a consequential discriminator reachable with a current lever? | attack now, build the missing tool, or shelf with a trigger |
| exploration vs formulation | Are problem frames still changing under new observations? | continue bounded construction or freeze the formulation |
| generation vs criticism | Is the declared candidate batch frozen? | before freeze: generate; after freeze: evaluate |
| conventional vs atypical combination | Does the transfer preserve a relation and yield a new prediction while retaining grounding? | admit a bounded atypical probe; reject distance-as-decoration |
| donor relation vs target claim | Is the source relation bounded independently, has `forging-novel-theses` recorded the correspondence or `MAPPING-BREAK`, and does the target have evidence? | route discovery to `systematizing-knowledge`, mapping to `forging-novel-theses`, then sign a denominator-complete `TRANSFER DISPOSITION`; donor success is not target evidence |
| transfer persistence vs honest reopening | Did every correspondence attempt break, or does a candidate retain a target-side discriminator? | preserve breaks and `REOPEN` when all maps fail; test a candidate only through a registered target-side contrast |
| novelty vs feasibility | Which axis is weak, and is it a hard exclusion or a portfolio trade? | preserve both values; do not collapse them |
| fast vs rigorous | Is the artifact exploratory/reversible or about to be believed/built upon? | rough generation may be fast; admission and evidence checks may not |
| persist vs pivot | Is a discriminating observation still reachable, and is information changing? | persist, pause with trigger, or retire the tested family |
| stable core vs high-risk probe | What loss can the program survive and what concentration reaches signal? | local portfolio allocation; no universal percentage |
| problem update vs HARKing | Was the new explanation formed after observing the result? | label it postdiction and register a later test; do not rewrite history |
| incubation vs continued work | Has a prepared human reached a concrete impasse, and is a bounded break appropriate? | optional human break; no agent analogue or guaranteed effect |
| human elicitation vs agent invention | Is a real owner available whose tacit context changes the frame? | ask bounded contrastive questions or record `UNELICITED`; never role-play the answer |

## Anti-slogan rule

A slogan is not a moderator. Reject:

- fixed percentages such as “problem setting is 80%”;
- monotonic claims such as “more agents always create more diversity”;
- scalar universals such as `impact × solvability × originality`;
- personality prescriptions where a checkable artifact is needed.

When no moderator can be answered from current evidence, mark the uncertainty and route the missing
fact to `raising-resolution`, the missing corpus position to `systematizing-knowledge`, an expensive or
irreversible load-bearing future bet to `acting-on-hypotheses`, or a cheap reversible probe to the
domain/plain executor.
