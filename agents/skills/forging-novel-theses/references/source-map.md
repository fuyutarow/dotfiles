# source-map — 原典 10 思考法 → 本スキルの工程への写像

このファイルは、本スキルが敵とする着想系書籍（山崎良兵『天才思考』型の「10 の思考法」）を、本スキルの
**どの Phase / ゲート / 除外**に変換したかの対応表である。lineage.md の主張「10 個は正味 **6 機能（分解・転移・
投射・動員・チーム・警戒/時間）＋ 2 気質フィルタ**に収束する」を、写像として具体化する。

2 層構成：
- **(1) 機能マップ** — 本スキル *自身* から検証可能。原典の正確な章題に依存しない。これが実質的な契約。
- **(2) 章題マップ** — 原典の 10 章題そのものへの写像。一次資料で確認できた場合のみ埋める。

---

## (1) 機能マップ（原典の章題に非依存 — 本スキルから検証可能な契約）

6 機能 + 2 気質フィルタが、本スキルのどこに着地するか。各行は SKILL.md の該当箇所を名指しする。

| 機能 / フィルタ | 着地点 | why here（1 行） |
|---|---|---|
| **分解** | Phase 1a（G1：箱B ≥ 1） | 原始要素まで割り「制約を装った慣習」を名指す訓練可能手続き。生成エンジンの前半。 |
| **転移** | Phase 1b（G2：新予測 ≥ 1） | 関係構造の写像（structure-mapping）で緩和策を運ぶ訓練可能手続き。生成エンジンの後半。 |
| **投射** | Phase 2a（未来外挿 → wedge） | 存在しない未来状態を SF プロトタイピングで外挿し、近未来 beachhead を逆算する。 |
| **動員** | Phase 2b（ナラティブ：説得 / 知覚変容） | 未来状態を伝達可能にし人を動かす機能。deck の DELIVERY ではなく thesis の中身まで。 |
| **気質フィルタ①：合意非依存（逆張り）** | Phase 0 ゲート（Thiel の問い、1 文） | 訓練不能な *気質*。install できないので判定して記録するだけ（停止しない）。 |
| **気質フィルタ②：内発性** | Phase 0 ゲート（pass / 要注意） | 同上。外的報酬が主成分なら逆風で折れる — 弱点として記録し Phase 4 で晒す。 |
| **チーム（運用）** | 境界外 → `boundaries.md`（除外運用層） | 個人の生成認知でなく組織 *運用*。相補的チーム編成は Wasserman 層として除外。 |
| **警戒 / 時間（運用）** | 境界外 → `boundaries.md`（除外運用層） | 脅威の定点監視（Grove 変曲点）と時間選好の固定（Bezos）は運用手続き。生成の外。 |

**写像の要点**：訓練可能な生成 4 機能（分解・転移・投射・動員）だけを Phase 1–2 に工程化し、2 気質フィルタは
Phase 0 の *ゲート*（判定・記録・非停止）へ、2 運用機能は *境界外* へ落とす。原典が同じ「◯◯思考」の語尾で
並べて抽象度を混ぜたもの（lineage.md 欠陥 1）を、階層で分離したのがこの表である。

**原典に無く本スキルが新設した層**：制御ループ 4 機能 = **反証（Phase 3a / G3）・タイミング（3b）・資本適合（3c）・
撤退（3d）**。着想系書籍が丸ごと欠く層であり（lineage.md 欠陥 2）、上表のどの原典機能にも対応先を持たない。
これが本スキルの実利の中心。

## (2) 章題マップ（原典 10 章題 → 変換先） — 検証済み

一次資料（版元ドットコム = 発行：日経BP の verbatim 目次、日経BOOKプラスの「はじめに」、著者インタビュー）で
10 章題を確認済み。書名『天才思考』, 山崎良兵著, 日経BP, ISBN 9784296209699（構造：序章 + 第1–10章）。
各章 = 1 思考法。以下は原典の思考法 → 本スキルの Phase / ゲート / 除外への写像。

| # | 原典の思考法（章題） | 正味機能 | 変換先 |
|---|---|---|---|
| 1 | 情熱思考（大好きなことに人生を賭ける） | 気質：内発性 | **Phase 0 ゲート**（内発性：pass / 要注意） |
| 2 | アナロジー思考（「知識の幅」が革新の源泉） | 転移 | **Phase 1b**（G2：関係構造の写像 + 新予測） |
| 3 | 第一原理思考（前提を疑いゼロから再構築） | 分解 | **Phase 1a**（G1：箱B = 制約を装った慣習 ≥ 1） |
| 4 | 反逆思考（あらゆる革新は反逆から始まる） | 気質：合意非依存 | **Phase 0 ゲート**（合意非依存 = Thiel の問い、1 文） |
| 5 | パラノイア思考（未来のリスクを察知） | 運用：警戒 | **境界外**（`boundaries.md`：Grove 変曲点の定点監視） |
| 6 | 物語思考（人を動かすのは論理より物語） | 動員 | **Phase 2b**（ナラティブ：説得 / 知覚変容を明示） |
| 7 | チーム思考（偉業は一人では成し遂げられない） | 運用：チーム | **境界外**（`boundaries.md`：Wasserman 相補的チーム編成） |
| 8 | SF思考（未来を想像できる者だけが未来を創る） | 投射 | **Phase 2a**（SF プロトタイピング → wedge / beachhead） |
| 9 | 長期思考（短期利益より長期の成功） | 運用：時間 | **境界外**（`boundaries.md`：Bezos 型 時間選好の構造的固定） |
| 10 | アート思考（理性を超え心を震わせる） | 動員（知覚変容側） | **Phase 2b**（ナラティブの *知覚変容* 極 — 枠の差し替え） |

**10 → 6+2 の収束の確認**：分解(3)・転移(2)・投射(8)・動員(6,10)＝生成 4 機能 → Phase 1–2。気質 2 個(1,4)
→ Phase 0 ゲート。運用 3 個(5,7,9)＝チーム + 警戒/時間 → 境界外。動員に 2 章(物語=説得寄り / アート=知覚変容寄り)
が写るため章数は 10、正味機能は 6+2。lineage.md の収束主張と整合する。

**原典が持たない層（再掲）**：反証・タイミング・資本・撤退（Phase 3a–3d）は 10 章のどれにも対応先が無い。
原典を写し切ってもこの制御ループは埋まらない — だからこそ本スキルの中核として新設されている。
