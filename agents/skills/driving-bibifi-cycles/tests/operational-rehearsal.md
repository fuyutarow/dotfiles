# Operational rehearsal — instruction quality is not execution proof

Freeze these checks before the trial. Use isolated temporary paths and actual supported tools.
Never use a live research checkout, dataset or another actor's job as a failure-injection fixture.
The same declared scope and bounds apply to every worker; no numerical research job is needed.

| Check | Exercise | Observable acceptance |
|---|---|---|
| Short independent returns | Separate workers produce a located interface check and a protocol counterexample on disjoint paths | Both artifacts exist with exact input binding; neither waits for the other |
| Changed input after hand-back | Revise the interface while retaining the first proposal; resume its worker through the real follow-up tool | New artifact cites the new input; old proposal remains historical and is not consumed as current |
| Consumer integration | Parent reads back the consumer artifact and its binding | Actual output matches the selected current contract; mere “done” text fails |
| Parent intervention across events | Deliver a changed premise after initial inspection while a real bounded worker awaits disposition | Parent observes actor state, rebriefs or interrupts through actual tools, then consumes the current return |
| Rejected start | Exercise a harmless rejected argument check and a permitted terminating readiness command | Failed request never becomes running; exit success is terminal, not ongoing execution |
| Active worker interruption | Interrupt an owned file-only waiting actor after its partial artifact exists | Tool observes running→interrupted; partial artifact remains; do not claim child/resource cleanup without a child/reservation |
| Installed process cap | Use existing P7 runner on an owned, tiny non-compute lifecycle probe with a short deadline | Effective admission, real timeout, no surviving owned child/group and reservation released |
| Unsupported runtime | If P7 or a needed tool is unavailable, retain exact failure | Report capability unverified/blocked; no fallback that bypasses the required runner |
| Scope containment | After every trial, inspect only owned paths/process identities | No live project mutation, external message, orphan job or unbounded wait |

Record tool IDs, exact versions, input/output locators, elapsed/return times and failure receipts.
Archive only small nonsensitive fixture artifacts with the evaluation receipt where appropriate.
These checks establish capability in this environment. They do not measure real R&D throughput.
Static regression cases and OLD/NEW answer comparisons remain useful but cannot substitute for these receipts.
For an improvement claim, run a matched real task and report valid discovery/time under the same workload.
