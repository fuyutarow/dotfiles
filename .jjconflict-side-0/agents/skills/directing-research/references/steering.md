# Steering a research portfolio

> **Sole home**: comparison, allocation, and reopening across at least two independent research
> directions. One expensive/irreversible hypothesis tree and its win/kill/loss conditions belong to
> `acting-on-hypotheses`; a cheap deterministic reversible probe belongs to the domain/plain executor.

## 1. Portfolio artifact

```markdown
| Direction | Independence basis | Risk tier | Allocation cap | Latest discriminating result | Information gained | Current block | Next review |
|---|---|---|---|---|---|---|---|
```

Independence is causal, evidential, or resource-based—not merely a different project name. If every
direction depends on the same data source, instrument, or scientific assumption, state that shared
failure mode.

## 2. Safe progress plus bounded high-risk probes

Maintain:

- a stable core that compounds reliable capability or evidence;
- bounded probes with asymmetric upside and explicit loss caps;
- enough concentration that at least one bet can reach a discriminating result.

This is not a universal barbell percentage and not a mandate to fund high-risk work. Observational
bibliometrics suggests risky work can be rare, discounted, and occasionally high-impact; it does not
identify the right allocation for this program.

## 3. Update on information, not local metric alone

For each review window, record:

```markdown
- Prior uncertainty:
- Discriminating observations obtained:
- Alternatives retired or added:
- Remaining uncertainty:
- Access / measurement block:
- Information gained per scarce resource:
```

Use this to compare directions. `dLearning/dt` is a program shorthand, not an optimizer learning rate
and not a mechanically validated scalar. Preserve the underlying observations.

## 4. Reopen rules

Choose the lowest transition that the result actually changes:

- unexpected but unverified observation -> `raising-resolution`;
- missing explanation for a selected problem -> `forging-novel-theses`;
- one gated expensive/irreversible tree gained a new node -> `acting-on-hypotheses`;
- one cheap reversible probe is decisive -> domain/plain executor, then return the result here;
- systematic controlled result changes what the problem is -> `directing-research` problem construction;
- evidence is mature enough to claim -> `arguing-research-papers`.

Do not treat a null result as proof that a domain is empty. Retire only the tested family and state its
boundary.

## 5. Direction-level persist / pause / retire

Use three verdicts:

| Verdict | Condition |
|---|---|
| persist | recent work produced a discriminating observation and the next uncertainty is reachable |
| pause | the current block is access, instrumentation, or missing prerequisite; name the reopening trigger |
| retire tested family | the family boundary is explicit, meaningful variants were tested, and further work repeats the same non-discriminating result |

Elapsed time and sunk cost are not evidence. Difficulty alone is neither a persist nor retire signal.

## 6. Cardinality guard

If there is only one tree—or it is not yet known whether apparent directions are independent—apply the
cost/reversibility gate. Expensive, irreversible, load-bearing uncertainty starts in
`acting-on-hypotheses` Map; a deterministic, obvious, cheaper-to-run, reversible probe goes to the
domain/plain executor. Return here with the result, or when at least two independent directions exist
and must be compared or allocated.
