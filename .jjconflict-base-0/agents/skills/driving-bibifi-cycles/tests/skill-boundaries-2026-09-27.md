# Research skill composition — split/merge decision

User request: audit the related skills, including forming-hypotheses-from-anomalies, rather than patch BIBIFI alone.
Baseline: dotfiles d44de2f (BIBIFI v2609.4.1, forming v2609.2.1, forging v2608.2.0).

## Located defects

| Baseline locus | Defect | Correction |
|---|---|---|
| forming SKILL.md LAW / forging entry gate | “No candidate: go to forging and come back with a seed” obscured that an observation itself is a seed | Own the explanatory attempt; use a located observation/account/constraint for a deliberate transformation |
| forming description, boundaries and N9 | Frame/donor availability overrode a request to explain an anomaly | Purpose chooses explanation versus transformation |
| forming boundaries | Called forging output ranked and distinguished one versus many, although forging allowed one or more and forbade ranking | Remove cardinality as the cut; keep both outputs unranked |
| forming boundaries / forging routing | Only a TRANSFER packet with introduced terms was named as a valid seed | Any located account may seed ACCOUNT; TRANSFER still requires the actual donor set |
| forging return/boundaries | All consumers were sent through formal section machinery | Qualify that profile; ordinary authorized R&D returns to its task owner/BIBIFI |
| BIBIFI composition | Specialist completion and continuous task completion were not joined explicitly | Same agent can apply multiple skills and immediately consume each return |

## Retain, consolidate, retire

Retain the three packages: explaining a contrast, transforming a seed and operating an evidence-driven loop
have distinct inputs, decisions and reusable standalone requests. Consolidate ongoing work selection and
consumption in BIBIFI, with a single composition map at `references/skill-composition.md`.
Retire the donor-first/cardinality routing rules and the successful-hypothesis prerequisite interpretation.
No new skill, dispatcher, record service or authority hierarchy is introduced.

Retain evidence qualification, proof certification and theory revision separately. A valid measurement,
a checked derivation and a changed theoretical dependency are different conclusions.
Retain AOH for costly commitments; BIBIFI may schedule Build→Measure without taking its judgment.
The AOH description's older Tiger-only integrity wording remains a separate routing ambiguity;
its body already requires the evidence owner. This patch does not claim a full collection cleanup.
