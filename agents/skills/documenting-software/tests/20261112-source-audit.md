## Operational derivation for this incident

editorial records is a local response to mixed responsibilities in the reviewed spec. The inventory
connects examples to existing sources, but no single source supplies this five-way scheme.
It is a way to inspect mixed statements, not a mandatory file tree or section template.
Reader-operation and adoption checks are also bounded practitioner guidance. Neither the source
inventory nor a synthetic agent evaluation proves human learning or project adoption effects.

The skills retain one owner per substantive question, with useful summaries and examples allowed.
Binding implementation decisions remain binding when moved; changing their location does not
weaken their authority. A focused API reference is not required to become an application tutorial.
