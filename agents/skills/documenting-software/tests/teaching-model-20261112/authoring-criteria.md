# Frozen before authoring dispatch

An independent documentation author is given only the assigned skill description and Rill facts.
Same task and facts, one task per fresh session, no other product or regression inputs.
Assess authored explanations, not their claims about their own quality.
Useful behavior: builds from a beginner's familiar file/line model to why chunks/cells/records
must be distinguished, then shows one concrete split/quoted-newline example and what it changes.
Page duties let a reader learn that model before exact API lookup; questions include failure/end
of input, runtime-vs-static typing, consumer pacing or restart/external-effect limits as relevant.
No invented parser API, resumability, static inference or exactly-once guarantees.
A candidate improves only if it teaches a usable causal model missing/less clear in baseline,
without newly misleading the beginner. A new heading count or longer list is not an improvement.
This tests authoring under description-only attention, not review accuracy or human comprehension.
