# Boundaries — thesis genesis has one home

## Decisive predicate

Ask:

> Does a selected problem/frame already have a thesis candidate adequate for testing?

- **No** -> `forging-novel-theses`.
- **Yes; compare it with other candidates or decide whether it matters locally** -> `directing-research-sections`.
- **Yes; earn evidence or commit/kill it** -> apply the downstream-exposure gate:
  expensive/irreversible -> `acting-on-hypotheses`; cheap/deterministic/reversible -> domain/plain
  executor, then return `EXECUTOR RESULT` to `directing-research-sections`.

## Reciprocal owner table

| Neighbor | Neighbor owns | This skill receives / returns |
|---|---|---|
| `supervising-research-programmes` | programme problem construction/selection/formulation; why-now; portfolio and global transitions | the selected frame reaches a granted section through a mandate; receives only a frame-change/reopen request, not candidate packets |
| `directing-research-sections` | local semantic dedup, candidate admission, transfer disposition, and coverage-gap recovery | sends the selected-frame brief; receives unranked packets; may send one coverage-gap packet and receive one targeted candidate or `COVERAGE GAP` |
| `systematizing-knowledge` | bounded corpus position and novelty evidence | receives prior/novelty position; returns `UNVERIFIED` gaps for corpus work |
| `systematizing-knowledge` (transfer branch) | target-agnostic donor discovery and frozen `DONOR SET` | receives a source-side relation question; returns located donor IDs, comparison or `SINGLE-DONOR LIMIT`, source boundaries, path, and SHA-256 — never a target mapping |
| `surfacing-blind-spots` | assumption audit, negative-space search, and human tacit-knowledge elicitation | receives only a `Blind-spot packet` handoff; admits TACIT facts only from answered rows with `HUMAN:<owner>@<attestation-locus>` provenance |
| `raising-resolution` | one present artifact, anomaly, constraint, or source fact | receives cited observation; returns dependencies needing inspection |
| `acting-on-hypotheses` | one expensive/irreversible selected tree: Map, test threshold, outcome table, commit/pivot/kill | receives nothing until a candidate is selected and its hard gate fires; returns no test mechanics |
| `arguing-research-papers` | one finished evidence-backed manuscript claim | if paper diagnosis reopens ideation, receives a new selected frame; otherwise no fire |
| `orchestrating-agents` | agent roles, blindness, evidence visibility, critique release, veto, acceptance | domain packet and batch-freeze criterion first; orchestration wraps generation without owning them |

## Common braided asks

| Ask | Ordered route |
|---|---|
| “How do I do creative research from topic to experiment?” | `directing-research` emits only a routing decision -> `supervising-research-programmes` selects/publishes the frame -> `directing-research-sections` charters a granted section -> HERE only at `thesis-missing` -> section admission -> [`acting-on-hypotheses` if hard-gated / domain executor if cheap-reversible] |
| “This controlled residual may imply a new theory.” | `raising-resolution` -> `supervising-research-programmes` frame decision -> granted `directing-research-sections` section -> HERE |
| “Generate candidates and choose the best.” | HERE generates -> `directing-research-sections` freezes/deduplicates/selects locally |
| “Generate candidates and design kill experiments.” | HERE generates -> `directing-research-sections` selects -> [`acting-on-hypotheses` if hard-gated / domain executor if cheap-reversible] |
| “Elicit what the operator knows but never documented, then generate theses.” | `surfacing-blind-spots` elicits and hands off sourced rows -> HERE uses only those rows as TACIT seeds |
| “The five generated candidates deduplicated to one.” | `directing-research-sections` returns one coverage-gap packet -> HERE regenerates once in the named cell or emits `COVERAGE GAP` |
| “Find analogs in adjacent fields, map them to this selected target, and preserve failed mappings.” | `systematizing-knowledge` compiles `DONOR SET` -> HERE runs `--donor-set`, maps roles, and returns `CANDIDATE` or `MAPPING-BREAK` -> `directing-research-sections` preserves the attempt denominator |
| “Use five agents to ideate independently.” | HERE fixes packet/routes -> `orchestrating-agents` fixes blindness/topology -> HERE receives packets |
| “Reviewers say the completed paper is not novel.” | `arguing-research-papers` diagnoses claim/position; only a deliberate programme reopen by `supervising-research-programmes` and a new granted section reach HERE |

## MUST-NOT-OWN list

This skill must not contain or require:

- research-problem ranking;
- impact/feasibility/novelty scoring;
- human tacit-knowledge elicitation or simulated practitioner testimony;
- semantic deduplication;
- fresh-lever or why-now admission;
- kill experiment or pass/fail threshold;
- WIN/KILL/LOSS or withdrawal criteria;
- time-to-truth, runway, capital fit, market timing;
- portfolio allocation;
- paper positioning;
- agent dispatch or acceptance mechanics;
- target-side evidence, adoption, retirement, or a transfer-disposition verdict; a donor success is
  source-side evidence only.

If any appears in a template or validator, the collection has regressed.

## Co-fire versus race

Sequential handoffs are legitimate co-fire. Two skills independently emitting the same decision artifact
is a race.

Examples:

- candidate packet here + selection record in `directing-research-sections` = clean sequence;
- coverage-gap packet from `directing-research-sections` + one targeted regeneration here = clean recovery;
- candidate packet here + kill threshold here = one-home violation;
- target-agnostic donor set there + selected-target correspondence here = clean sequence;
- `MAPPING-BREAK` here + `TRANSFER DISPOSITION` in `directing-research-sections` = clean negative-result
  sequence; deleting the break to improve the candidate list is a denominator violation;
- `TACIT` seed synthesized here without an answered
  `HUMAN:<owner>@<attestation-locus>` probe row = fabricated evidence;
- domain packet here + blind-role contract in `orchestrating-agents` = orthogonal co-fire;
- novelty claim here without corpus evidence = laundering; use `UNVERIFIED`.
