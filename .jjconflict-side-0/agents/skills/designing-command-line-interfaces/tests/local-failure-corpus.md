# Local failure corpus

| Failure | Gate that prevents it | Required observable |
|---|---|---|
| “users” hides CI and automation obligations | C0 | named consumer/regime rows |
| a parser convention is assumed portable | C1 | parser profile plus ambiguous/invalid case |
| `--dry-run` is treated as inherently safe | C2 | suppressed effects and forecast fidelity |
| progress corrupts a machine parser | C3 | stdout/stderr and framing matrix |
| a numeric exit code is mistaken for diagnosis | C4 | outcome/recovery matrix |
| human output changes silently break scripts | C5 | stable route and compatibility receipt |
| a negative test path is never exercised | C5 | rejected command/input transcript |

These are contract failure classes, not empirical proof that every command has each risk.
