Retain these distinct owners; no new skill is admitted. Retire duplicated or conflicting fleet
operation rules into the owners above. Keep experimental evidence separate from deployment claims.
Keep milestone-level learner/standard-metric requirements separate from local diagnostic artifacts.
The shared default fleet prompt must point to the same role rules; project overrides remain untouched.

## Practical replacement

Before the next official run, repair or establish complete execution binding and exercise one tiny
actual runner fixture reaching the changed CM/TM/writer path. Select the next discriminator from its result.
If resource admission blocks it, identify the owned lower-priority reservation and its safe stop point.
Prefer a launcher-supported immutable snapshot to freezing all development for a queue; otherwise
serialize only the necessary window and re-slice. Never assume snapshot support from a clean worktree.
On a null ablation, inspect whether the fixture could exercise the mechanism before excluding it globally.
Use old performance code as a tested transfer candidate, not proof that the new invocation is fast.

The two-minute target remains a target; ten minutes remains an experiment ceiling. Ticket scope is
a checked, consumed outcome, not a universal function count or a fixed number of agents.
