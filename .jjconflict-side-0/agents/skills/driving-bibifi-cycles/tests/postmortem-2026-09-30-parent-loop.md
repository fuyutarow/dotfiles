## Root-signed distillation

Keep BIBIFI as work-selection owner and C0 as operational-coordination owner. Do not add another
agent type, scheduler or record system. C0 now closes observation→decision→action→consumer receipt.
Limit inspection by one named decision/job set, not by an arbitrary count of read operations.
Parent-owned readiness/identity/receipt checks are operational evidence, not independent scientific verification.
Deliverable authorship and any required independent verifier remain separate.

Replace long private queues with one first useful return and a conditional parent backlog.
Preserve preauthorized branches whose guards, bindings, authority and budgets still hold.
Apply the same return discipline to theory, build, integration and launcher repair.
Distinguish artifact dependency from worker-queue dependency; freeze/reassign safely or split a disjoint interface.
Separate necessary regressions/readiness from unrelated suite completion; never skip a required release oracle.

## Frozen rehearsal criteria

Use fresh OLD/NEW coordinators on isolated same-shape inputs and real preassigned file workers.
After each coordinator inspects v1, deliver the same v2 upstream change. Require actual worker
update/interrupt, bounded return, preserved partial work and consumer acceptance bound to the current artifact hash.
A real rejected argument-readiness attempt must remain unstarted; normal terminal success must not be reported still running.
No numerical experiment, GPU job, production file mutation or new scheduler is part of the rehearsal.
All actors have finite lifetimes; root stops any remaining actor at expiry.

This exercises actual agent coordination and file consumption, not real R&D throughput or kernel resource cleanup.
Both arms receive the same events without the criteria/expected answers. Record a tie honestly.
