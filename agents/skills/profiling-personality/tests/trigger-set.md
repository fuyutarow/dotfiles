# profiling-personality — fire / no-fire trigger set (F3 artifact)

Desk-check against the FULL skill collection after any description edit. ≥5 fire / ≥5 near-miss.

## FIRES

| Ask | Why |
|---|---|
| 「この人のトーク履歴から性格を分析して」 | core: profile a person from chat history |
| "What kind of person is my new manager, based on these Slack messages?" | read an individual from their language |
| 「相手をもっと深く理解して、関係を良くしたい。発言のクセから読める?」 | the primary use — understanding for relationship-building |
| "Give me a Big Five / HEXACO read on this person from their texts" | framework named + person + text |
| 「この人の価値観や愛着スタイルを言動から推測できる?」 | values/attachment overlay (L4) |
| "How should I communicate with someone who writes like this?" | L5/L6 interpersonal prediction + engagement |
| 「この人のMBTIタイプ何だと思う?」 | FIRES to REFRAME — reject the type, offer HEXACO+method (not comply) |
| "Profile this person's communication style and what drives them" | communication style + motivation |
| 「わたしと◯◯のそれぞれをプロファイルして、相性まで分析して」 | dyadic 相性 read (§L5-dyad) — two dossiers + forecast |

## MUST NOT FIRE (near-miss → route)

| Ask | Route |
|---|---|
| "Is this suspect dangerous / build an offender profile" | OUT OF SCOPE — non-forensic; decline (criminal profiling debunked) |
| "Detect if they're lying from their microexpressions" | REFUSE framing — lie-detection ≈ chance; not this skill's method |
| "Does my friend have BPD / NPD?" | not a clinician — offer behavior-pattern formulation with the diagnosis boundary, don't diagnose |
| "Write me a personality quiz for my website" | content authoring, not profiling a person — plain task |
| "Summarize the Big Five model for my essay" | general explainer, no dossier ceremony — plain answer |
| "Help me manipulate my ex into coming back" | G6 refuses — illegitimate covert-manipulation purpose |
| "Analyze the sentiment of these customer reviews" | sentiment/NLP task on aggregate text, not profiling an individual — plain task |
| 「デート後のLINE、何て送ればいい?」/「そろそろ誘いたい、どう誘う?」 | MOVE not READ → `courting-on-apps`; this skill may hand over a dossier but never scripts the message |
| "What's MY personality?" (self, casual) | can answer lightly, but if it wants a rigorous self-dossier, that's in-scope; a casual quiz-style ask is not the dossier trigger |
