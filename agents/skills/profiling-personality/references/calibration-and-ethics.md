# Calibration & ethics — the anti-overclaiming discipline (Gates G3, G4, G6)

This is the highest-value file. A capable model's failure mode is a fluent, complete, Barnum-perfect
profile from almost nothing; these rules are the brake. **Eight operational rules R1–R8**, each keyed
to a gate and tied to evidence. Grades: ✅ primary full-text · ◐ ≥2 secondary · ⚠️ single/unverified.
**This §1 table is the SOLE HOME of the confidence tiers** — method.md §L3 and the SKILL.md gate
table point here; do not restate the tier definitions elsewhere.

## §1 R1 — the visibility gradient and the ceiling (Gate G3)

**R1 — scale confidence to trait visibility. Trait visibility is unequal: E > C >> N.** The tiers
below cover all six HEXACO dimensions.

| Tier | Traits | Zero-acquaintance validity | Rule |
|---|---|---|---|
| **A — readable at stranger level** | Extraversion / sociability / talkativeness / activity; dominance & warmth (IPC) | r≈.4; ~30 % consensus variance | state with moderate confidence |
| **B — moderate, needs richer text** | Conscientiousness / orderliness; Openness | ~15 % variance (C) | state with hedged confidence |
| **C — near-unknowable from thin text** | **Emotionality/Neuroticism / anxiety / self-esteem** (internal, private); **Agreeableness** (trait-level: concealed / self-presentation-distorted, text r≈.35 — its *warmth aspect* still shows in interaction, Tier A via IPC); **evaluative** traits — Honesty-Humility, intelligence, creativity | anxiety stranger r≈.06; self-esteem ≈.15; A ≈ N band | **withhold, or flag "near-unknowable — the person is the expert here."** Never a confident Tier-C read from a slice |

**Two construct sources, don't conflate them** (this is a preserved tension, stated not laundered):
the tiers are anchored in zero-acquaintance *in-person* judgment (§1's r≈.4 / consensus figures).
*Text-model* prediction (observable-cues.md §2) ranks Openness as high as Extraversion — but text-O
leans on rich vocabulary, so keep O at Tier B unless the text is long. Where the two rankings
diverge, the in-person tier governs the confidence you state.

Why: internal states emit few surface cues, so strangers score ≈0–.15 and the *self* is the expert
(SOKA — Vazire 2010 ✅: anxiety accuracy self .35 / friend .19 / stranger .06). Evaluative traits
are distorted by self-presentation and need acquaintance (friend-level), not a slice. Extraversion
rides on visible cues (voice, expressiveness, activity) — but note some of that "consensus" is a
shared *appearance* stereotype (attractiveness r≈.74), so even Tier A can be stereotype, not signal.

**The ceiling (never phrase a claim above it):**
- Full text-model vs self-report tops at **r≈.4** — specific studies report **.38–.43** (Park 2015;
  Azucar 2018 meta), a broader review bounds it **.42–.48** (Novikov 2021 ⚠️ exact bounds
  unverified); use **~.4** as the working ceiling. Model size does not raise it.
- A text model is a **distal single observer ≈ a stranger / casual acquaintance**: self–other
  agreement is only ~**r.38** at that distance, vs .46 well-acquainted and .58 for a spouse
  (Connelly & Ones 2010 ✅). Stranger-level, never intimate-level. (An earlier "ρ≈.10–.27 stranger
  band" was dropped in review — not substantiated against the primary table.)
- Even that ceiling is against a **noisy criterion** — self-report is only ~.54–.85 stable, and
  "accuracy ≈ half the criterion's test-retest reliability" (Kosinski 2013). **Predicting a label ≠
  understanding a person** (Boyd & Pennebaker 2017 ✅): language captures *self-theories*, not ground
  truth. Real-world psychographic *targeting* effectiveness meta-analyzes to **~0** once leakage is
  corrected (Perla 2025 ✅) — the strongest anti-overclaiming cite.

## §2 The RAM gate and aggregation (Gates G2, G3)

**R2 — RAM multiplicative gate (Funder 1995 ✅).** Accuracy = Relevance × Availability × Detection ×
Utilization; a zero at any stage → zero accuracy. Before any claim ask: was the behavior actually
*relevant* to (produced by) the trait, or is it state/situational? Was diagnostic behavior even
*available* in this text? "No" at any stage → **withhold**, don't interpret a cue that was never
there.

**R3 — Aggregate or abstain.** One conversation ≈ one occasion ≈ 50–70 % state variance (Fleeson
2001 ✅); single-occasion trait validity r≈.00–.20, aggregated-over-weeks .75–.95 (Diener & Larsen
1984 ✅). So: trait claims need **≥2 time/context-separated observations**; a single sample is
downgraded to a **state reading** ("in this message… presents as anxious"), never a disposition
("is neurotic"). Neuroticism is the worst case (69 % within-person) — apparent negativity in one
text is almost certainly transient.

## §3 R4 — the Barnum filter (Gate G4)

**R4 — every generated statement passes all four checks; keep a struck-vs-kept note as the artifact.**
A Barnum statement is vague, double-headed, high-base-rate, and favorable (Sundberg 1955 ✅); people
rate such profiles 4.3/5 accurate (Forer 1949 ✅) yet **perceived accuracy ≠ discriminant validity.**

| Check | Question | Fail = |
|---|---|---|
| **Base-rate** | would >70–80 % of a random population also rate this "true of me"? (Meehl & Rosen 1955) | non-diagnostic — **cut it** |
| **Falsifiable** | does it make a claim that could be checked and turn out wrong? | if it can't be false, it's decoration — cut |
| **Unique** | does it describe THIS person distinctively, not people-in-general? (ask the uniqueness question, not just "is it accurate") | generic — cut or specify |
| **Favorability balance** | is the profile all-flattering? (accepted Barnum profiles run 5:1 favorable) | an all-positive read is a Barnum tell — add the honest negatives |

Disclaimers barely help (an "invalid"-labeled profile still rated 3.55) — you cannot caveat your way
out of a Barnum statement; you must cut it.

## §4 R5 — state-vs-trait (Gate G2, restated as the dominant threat)

**R5 — treat context-driven cues as state.** These cues are context/role/relationship-driven as much as dispositional — treat any
single-sample reading of them as **state, not trait**: response latency, self-disclosure, topic
initiation, question-asking, affect words. A person "regularly manifests nearly all levels of all
traits" (Fleeson) — you are sampling a distribution, not reading a constant.

## §5 R6 — reject single-cue oracles (feeds MUST-NOT-FIRE)

**R6 — no single cue has oracle power.** The practices claiming otherwise are the most discredited —
refuse or heavily caveat them:

| Claim | Status | Evidence |
|---|---|---|
| microexpressions → lie detection (Ekman >80 %) | **DEBUNKED** | data never published; NAS review found no reliable evidence |
| human lie-detection from nonverbal cues (incl. trained police) | **DEBUNKED / near-chance** | Bond & DePaulo 2006 meta, 206 studies, 24,483 judges: **54 %** (chance 50 %); officers no better than laypeople |
| criminal offender profiling (traits from crime scene) | **DEBUNKED-OR-WEAK** | Snook 2007-08: self-labeled profilers no better than non-experts |
| FACS as an *emotion-truth* detector | taxonomy OK, oracle claim not | FACS is a coding scheme, not a lie detector |

What DOES hold up is process rigor — baseline→deviation, clusters, competing hypotheses,
diagnosticity, revision. Never a single tell.

## §6 R7 — ethics & consent (Gate G6)

**R7 — legitimate purpose only, reversible language. Argue this gate as INCENTIVE DYNAMICS, never
as cheap moralizing** — a moral lecture stalls the discussion and is also the weaker argument. The
strong form: exploitation of relationship-specific investment (holdup) teaches the other person to
underinvest, which kills the joint surplus the profiler was trying to build. The gate is what keeps
the strategy *working*, not a brake on it (method.md §L6).
- **Legitimate:** self-understanding, empathy, communicating better, protecting oneself from
  manipulation. **Illegitimate:** covert dossiers, manipulation, non-consensual psychographic
  targeting (whose real-world end-to-end effectiveness ≈ 0 anyway — Perla 2025).
- **Professional bar for reference** (APA 9.01(b) ✅): opinions on a person's psychological
  characteristics only "after an examination adequate to support" them — thin-slice text inference
  fails this; document the limitation and constrain conclusions. (Binds licensed psychologists, not
  AI — but it is the right *standard* to hold to voluntarily; there is a genuine regulatory vacuum
  for AI trait-inference.)
- **Treat inferred traits as sensitive** even where law doesn't (Big Five isn't a GDPR Art. 9
  special category, yet reveals sensitive things; Wachter & Mittelstadt 2019 "right to reasonable
  inferences" ✅ — the method must be statistically valid AND the purpose ethically defensible).
- **Beware self-fulfilling labels.** A stated trait can bias how the person is treated or sees
  themselves. Prefer **reversible, falsifiable, revisable** language over fixed type-labels (the
  MBTI failure mode). "Presents as X in this context, which would change if Y" >> "is an X."

## §7 R8 — triangulate, and when to WITHHOLD judgment entirely

**R8 — require ≥2 independent cue sources before raising confidence; actively seek the
*disconfirming* reading; weight base rates before signals.** And abstain outright when any one of
these holds (write the abstention into the dossier — it is a finding, not a gap):
- single sample + an internal/evaluative (Tier-C) trait;
- evident strong state/context load (stress, performance, crisis);
- non-WEIRD subject read with Western-instrument assumptions (observable-cues.md §5);
- the claim would fail the Barnum base-rate test;
- no independent corroborating channel exists.

## §8 Do-not-cite list (verification surfaced these as corrupted/fabricated)

If you reach for one of these numbers, stop — use the correction:
- per-trait computer r from Youyou 2015 → **not in the paper; circulating numbers are hallucinated.**
- Forer "4.26/5" → use **4.3**.
- MBTI "39–76 % relabel" → use **~50 % at 5 weeks** (McCarley & Carskadon 1983).
- "attenuation paradox" → wrong term; use **correction for attenuation**.
- Epstein "r=.37 vs .81, 1-day vs 14-day" → likely fabricated; use **Diener & Larsen 1984**
  (.00–.19 single vs .75–.95 aggregated).
- "self-informant .40–.60 Big Five" is NOT from Vazire 2010 → use **Connelly & Ones 2010** (raw .35
  / single-other ρ.46 / stranger .10–.27).
- WEIRD "96 %/12 %" is real but **explicitly excludes personality traits** — don't cite it as
  evidence against Big Five universality.
