can use and the questions the user's prompt has not supplied.

case, preserving the differences between command receipt, coordinator status and external effect.

or the authority/trust necessary for that workflow, without asserting an unobserved exploit.

and identifies which page should answer the conceptual question versus exact lookup/host detail.

requiring all setup or a full tutorial inside that API reference.

Accept a revision differential only if candidate contributes a useful grounded model/path decision
missing from the baseline, with no new material contradiction or narrow-reference overreach.
A different layout, more role names, or the same good/bad judgment is not useful evidence of benefit.
If both are already adequate or no meaningful difference occurs, return the revision.
This is a bounded synthetic test, not a measured human-learning or general-effectiveness claim.
